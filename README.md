### The challenge

The goal of this challenge was to build a recipe page based on the design provided by Frontend Mentor and make sure the page is responsive across different screen sizes.

Users should be able to:

* View the recipe page on different screen sizes.
* See a responsive layout that closely matches the provided design.
* Read the recipe information clearly and comfortably.

### What I learned

This project helped me strengthen my understanding of semantic HTML and responsive CSS.

Some of the main things I practiced were:

* Structuring a webpage using semantic HTML elements.
* Creating responsive layouts using CSS.
* Using Flexbox and CSS Grid to control page layout.
* Working with spacing, typography, borders, and colors.
* Using media queries to adjust the layout for different screen sizes.
* Paying attention to small details when matching a design.

One thing I particularly practiced was using CSS Grid and Flexbox together to create a flexible layout that works across desktop and mobile screen sizes.

I also learned that writing clean and well-structured HTML makes styling and maintaining a project much easier.
